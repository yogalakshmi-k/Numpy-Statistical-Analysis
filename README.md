# NumPy Statistical Analysis

## 📌 Project Overview
This project analyzes a numerical dataset using NumPy statistical functions to identify important patterns in student performance.

## 🎯 Objective
To practice statistical calculations using Python and NumPy.

## 🛠️ Tools Used
- Python
- NumPy
- Google Colab

## 📊 Dataset
The dataset contains student marks:

`[45, 50, 55, 60, 65, 70, 75, 80, 85, 100]`

## 📈 Statistical Calculations

| Statistical Function | Result |
|---|---:|
| Mean | 68.5 |
| Median | 67.5 |
| Standard Deviation | 16.13 |
| Minimum | 45 |
| Maximum | 100 |

## 🔍 Observations
1. The mean mark is 68.5, representing the average performance of the students.
2. The median is 67.5, which is close to the mean.
3. The marks range from 45 to 100, showing variation in student performance.

## 💡 Key Learnings
- Calculating mean and median using NumPy.
- Understanding standard deviation.
- Finding minimum and maximum values.
- Identifying patterns in numerical data.

## 📝 Interview Questions

**1. What is the difference between mean and median?**

Mean is the average of all values, while median is the middle value after sorting the data.

**2. When can median be more useful than mean?**

Median is more useful when the dataset contains unusually high or low values because it is less affected by them.

**3. What does standard deviation tell us?**

Standard deviation measures how spread out the data values are from the mean.

This project demonstrates how NumPy statistical functions can be used to summarize numerical data and understand patterns in student performance.
